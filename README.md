This is my personal **Cloud Infrastructure & DevOps Portfolio Website** built to showcase my experience across cloud architecture, infrastructure engineering, DevOps automation, Kubernetes, CI/CD, observability, and hybrid cloud environments.

The portfolio highlights:

- Google Cloud Platform architecture
- Cloud infrastructure and landing zones
- Kubernetes and GKE platforms
- Infrastructure as Code using Terraform
- CI/CD automation using Jenkins and Harness
- Hybrid Cloud and On-Premises infrastructure
- Apache Kafka and distributed systems
- Observability and monitoring
- Security and secure infrastructure
- Disaster Recovery and High Availability
- SRE and platform engineering practices
